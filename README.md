# java-racingcar-precourse 

# 중요 키워드 
    - n대의 자동차 -> 각 자동차에 이름 부여 가능 
    - 시도할 횟수 입력 받기 (Console.readline)
    - 자동차 전진 또는 멈춤 가능(0~9 무작위 발급, 4 이상일때 전진)
    - 경주 우승자 선별 

# 구현할 기능 큰 단위로 나누기
    1. 입력
        1) 자동차 이름 입력
            - 이름은 쉼표로 구분
            - 이름은 5자 이하만 가능
            - 잘못된 입력일 경우 예외를 발생시킴
        2) 시도할 횟수 입력
            - 1 이상의 정수만 입력이 가능
        
    2. 경주 진행
        - 각 라운드마다 모든 자동차가 전진 또는 멈춤 수행
        - 시도 횟수만큼 라운드 반복
        
    3. 자동차 객체(모델)
        - 자동차는 이름과 위치를 가짐
        - 전진 조건(0~9 중 4 이상일 때 전진)을 만족하면 한 칸 이동

    4. 출력
        - 각 시도 결과를 출력한다.
        - 가장 멀리 간 자동차(들)를 우승자로 출력
    

# 기능 구현 흐름 정리
    1. 사용자로 부터 자동차 이름, 시도할 횟수 입력 받기
    2. 입력값 검증 -> 유효하지 않으면 예외 발생(IllegalArgumentException)
    3. 0~9 랜덤 숫자 발급 후, 값이 4 이상이면 전진
    4. 시도 횟수만큼 라운드 반복
    5. 최종 위치 비교 후 우승자 출력
    

# 구현 목표
    - 객체 지향적 코드 구조로 구성
    - 읽기에 간결한 코드 구조로 구성
    - 컨트롤러에 최대한 적은 코드 배치
    - 최대한 model, view, controller 역할에 맞게 코드 구성
    - 큰 기능에서 작은 기능으로 범위 줄여나가면서 구현
