# java-racingcar-precourse 

# 중요 키워드 
    - n대의 자동차 -> 각 자동차에 이름 부여 가능 
    - 시도할 횟수 입력 받기 (Console.readline)
    - 자동차 전진 또는 멈춤 가능(0~9 무작위 발급, 4 이상일때 전진)
    - 경주 우승자 선별 

# 구현할 기능 큰 단위로 나누기
    - 입력
    - 출력
    - 전진/멈추는 동작
    - 우승자 결정하는 동작
    - 자동차 객체(모델)

# 기능 구현 흐름 정리
    1. 사용자로 부터 자동차 이름, 시도할 횟수 입력 받기
    2. 0~9 랜덤 숫자 발급 후, 값이 4 이상이면 전진 아니면 멈춤
    3. 우승자 발표 

# 구현 목표
    - 객체 지향적 코드 구조로 구성
    - 읽기에 간결한 코드 구조로 구성
    - 컨트롤러에 최대한 적은 코드 배치
    - 최대한 model, view, controller 역할에 맞게 코드 구성
    - 큰 기능에서 작은 기능으로 범위 줄여나가면서 구현
